7. Миграция и перенос данных средне

Похожие сервисы решают разные задачи. Сначала определи, что переносят: серверы, БД, файлы или огромный объём офлайн.

Что переносимСервис

MGN: серверы средне

Агент (Replication Agent) непрерывно реплицирует диски источника в staging area в AWS; потом cutover запускает серверы почти без простоя. Заменил Server Migration Service. VM Import/Export — разовый импорт образа ВМ, без непрерывной репликации и без минимального простоя.

⚠ Ты ошибался здесь«Lift-and-shift VM с минимальным простоем» → MGN + Replication Agent, а не VM Import/Export.

DMS и SCT

  • DMS: миграция БД с минимальным простоем; CDC (непрерывная репликация изменений) после полной загрузки. Источник остаётся рабочим. Нужен replication instance.
  • Homogeneous (Oracle → Oracle): DMS достаточно. Heterogeneous (Oracle → Aurora PostgreSQL): сначала SCT конвертирует схему и код, затем DMS переносит данные.
  • Цели: RDS/Aurora, DynamoDB, Redshift, S3, OpenSearch и др.

DataSync против Storage Gateway средне

  • DataSync — управляемое копирование NFS/SMB/HDFS/S3 → S3, EFS, FSx в обе стороны; расписание, проверка целостности, throttling, до 10× быстрее ручных инструментов. Агент on-prem. Через Direct Connect агент работает через VPC/service endpoint на private VIF.
  • Storage Gateway — постоянный гибридный доступ: File Gateway (SMB/NFS → S3, локальный кэш), Volume Gateway (iSCSI: stored — основной диск локально, cached — в S3), Tape Gateway (виртуальные ленты для backup-софта → S3/Glacier).
⚠ Ты ошибался здесь«Полностью управляемая, автоматическая и ускоренная репликация данных в AWS-хранилища по Direct Connect» → DataSync через service endpoint. File gateway — это файловая шара для приложений, tape gateway — виртуальная лента.

Snow Family

Физические устройства для офлайн-переноса: Snowcone (малый, 8–14 ТБ), Snowball Edge (storage optimized ~80 ТБ, compute optimized) и вычисления на периферии. Выбор: если передача по сети займёт > недели (сети мало или нет), берём Snowball. Данные шифруются; загрузка в S3 делает AWS. Для постоянного потока нужен DataSync/DX, не Snow.
