# AWS SAA-C03 Trainer (RU)

Личный офлайн-тренажёр к экзамену **AWS Certified Solutions Architect – Associate (SAA-C03)**. Статический сайт без бэкенда, сборки и зависимостей. Контент (конспекты, лабы, практические вопросы, пробные экзамены, карты) — JSON, интерфейс и тексты на русском, термины AWS на английском. Прогресс хранится в `localStorage`.

## Запуск

```bash
node serve.js          # → http://localhost:8000
# или: python3 -m http.server 8000
```

## Что внутри

- **13 тем** (по областям сервисов, с привязкой к 4 доменам экзамена): главное для экзамена + диаграммы, практические лабы (AWS CLI + Pulumi Python), практические вопросы с разбором.
- **5 пробных экзаменов** по 65 вопросов, 130 минут, веса доменов как в реальном blueprint; отчёт по доменам и полный разбор.
- **Карта сервисов** (`#/services`) — радиальный mind map ~145 сервисов и концепций в 12 категориях + режим «Шпаргалка»: ключевые факты, «выбирай, когда…», ловушки, сравнения «X vs Y», поиск с подсветкой.
- **Хаб вопросов** (`#/hub`) — все 429 вопросов как карточки знаний (тестируемое понятие, ожидаемый ответ, почему не другие, связи); граф «вопросы ↔ сервисы» с подсветкой по ключевым словам, фильтры по теме/источнику/сервису, самопроверка.
- **Дашборд** с прогрессом по темам и историей экзаменов.

> Вопросы оригинальные, в стиле SAA-C03 — это **не** реальные вопросы экзамена.

## Разработка

```bash
node --test                          # unit-тесты
node scripts/build-hub.mjs           # пересобрать content/hub/index.json
node scripts/validate-content.mjs    # валидация всего контента
```
