13. Типовые архитектуры и прочие сервисы

Паттерны архитектур, которые любит экзамен

ПаттернСостав
Статический сайтS3 + CloudFront (OAC) + Route 53 alias + ACM (us-east-1) + WAF
Трёхзвенное веб-приложениеRoute 53 → CloudFront → ALB (public) → ASG в private subnets (2+ AZ) → RDS Multi-AZ / Aurora, кэш ElastiCache; NAT для исходящего
Serverless web/APICloudFront + S3 (фронт) + API Gateway + Lambda + DynamoDB + Cognito
Асинхронная обработкаS3/API → SQS → ASG воркеров (масштаб по длине очереди) → результат в S3/БД; DLQ для ошибок
Fan-outSNS topic → несколько SQS/Lambda (разная обработка одного события)
Событийная автоматизацияисточник (Config/GuardDuty/Health/cron) → EventBridge → Lambda/SSM/SNS
Data lakeS3 + Glue Catalog + Athena/Redshift Spectrum + Lake Formation + QuickSight
Стриминг и аналитикаисточники → Kinesis → Firehose → S3/Redshift/OpenSearch; Flink для обработки
HybridDX + VPN backup, Storage Gateway/DataSync, Route 53 Resolver endpoints для DNS между on-prem и VPC

Каталоги и пользователи приложений

  • Directory Service: AWS Managed Microsoft AD (полноценный AD в AWS, trust с on-prem), AD Connector (прокси к on-prem AD), Simple AD (дёшево, базовый).
  • Cognito User Pools — регистрация, вход, MFA, федерация соцсетей/SAML, JWT; работает с ALB и API Gateway. Identity Pools — выдают временные AWS credentials.

EC2: семейства инстансов

СемействоДля чего
T (burstable)низкая средняя нагрузка со всплесками, CPU credits
M (general)баланс CPU/памяти, веб, приложения
C (compute)CPU: batch, кодирование видео, HPC
R / X (memory)БД в памяти, кэши, big data
I / D (storage)высокий IOPS, локальный NVMe (I), плотное хранение (D)
P / G (GPU)ML-обучение, графика; Inf/Trn — чипы AWS для инференса/обучения
  • Graviton (ARM) — лучше цена/производительность, если приложение собрано под ARM.
  • Elastic IP — статический публичный IPv4, платно, если не привязан; можно перекинуть на другой инстанс (failover).
  • Hibernate — RAM сохраняется на зашифрованный EBS; быстрый возврат состояния.
