Платишь ли ты за состояние

  • running — за инстанс; stopped — только за EBS (и Elastic IP, если не привязан); hibernated — EBS (RAM сохраняется на EBS); terminated — ничего.
  • Stop/start: данные instance store теряются, меняется публичный IP (Elastic IP остаётся), хост может смениться. Перезагрузка (reboot) данные сохраняет.

Сеть инстанса

  • ENI — виртуальная сетевая карта (private IP, SG, MAC), можно перенести на другой инстанс. ENA — enhanced networking до 100 Гбит/с. EFA = ENA + OS-bypass для HPC/ML (MPI/NCCL, Linux, лучше с cluster placement group). Нужен «OS-bypass, ниже задержка чем TCP» → EFA.

AMI, user data, лицензии

  • AMI привязан к Region (копируется между ними); user data выполняется при первом запуске; instance metadata — 169.254.169.254.
  • AWS License Manager — отслеживает лицензии и Enforce license limit не даёт запустить инстанс сверх купленных (Windows Server, SQL Server); алерт через SNS. Fleet Manager/RAM/ACM лицензиями не управляют.
⚠ Ты ошибался здесь
  • HPC с OS-bypass → EFA, не ENA/ENI.
  • Ограничить число запусков числом лицензий → License Manager с enforce limit.
  • Instance store не для постоянных данных: пропадает при stop/terminate/сбое хоста.

Lambda

  • Event-driven, до 15 минут, память 128 МБ–10 ГБ (CPU пропорционально), /tmp до 10 ГБ. Платишь за вызовы и GB·с.
  • Concurrency: лимит аккаунта на Region (по умолчанию 1000); reserved — гарантия и потолок для функции (защищает от «соседей» и от перегрузки downstream БД); provisioned — тёплые экземпляры против cold start.
  • В VPC: Lambda создаёт ENI в подсети; для доступа в интернет нужен NAT. Не хватит IP в подсети — throttling.
  • Источники: S3, SQS, SNS, DynamoDB Streams, Kinesis, API Gateway, EventBridge, ALB. Асинхронные вызовы: 2 ретрая, DLQ/destinations.
  • Lambda@Edge — у edge CloudFront (viewer/origin events).
