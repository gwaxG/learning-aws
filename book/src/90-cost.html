11. Стоимость

Где экономить

  • Compute: стабильная база — Savings Plans/RI; прерываемое — Spot; нерегулярное — On-Demand; нагрузка по расписанию — scheduled scaling и Instance Scheduler; Compute Optimizer предлагает right-sizing.
  • Serverless: платишь только за использование (Lambda, Fargate, DynamoDB on-demand, Aurora Serverless).
  • Хранение: подходящий класс S3, lifecycle, Intelligent-Tiering при неизвестном доступе; EBS gp3 вместо gp2; удалять неприкреплённые тома, старые snapshots, неиспользуемые EIP.
  • Передача данных: вход бесплатен; выход в интернет платный; между AZ платно; в одной AZ по private IP бесплатно; через VPC Gateway endpoint к S3/DynamoDB без платы NAT. CloudFront дешевле прямой раздачи с S3/EC2.
  • NAT Gateway стоит дорого (почасовая + за ГБ): трафик к S3/DynamoDB пускай идёт через Gateway endpoint.

Серверно и бессерверно по цене

Типовые «most cost-effective»
  • Нерегулярная короткая нагрузка → Lambda, а не EC2.
  • Устойчивая нагрузка 24/7 на 1–3 года → Savings Plans/Reserved.
  • Отказоустойчивый batch → Spot (+ Spot Fleet/ASG mixed).
  • Редкий доступ к данным → S3 IA/Glacier; неизвестный → Intelligent-Tiering.
  • Раздача статики → CloudFront + S3, не EC2.
